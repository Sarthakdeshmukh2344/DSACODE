## Project Title: Bank Account Indexing Application Using Balanced BST and AVL Tree

The Bank Account Indexing Application is a data structures project developed using C++. It uses Binary Search Trees (BST) and AVL Trees to store and manage bank account numbers efficiently. The main objective of this project is to rebuild a balanced BST from its inorder sequence and compare its height with an AVL tree constructed through insertion.

In this project, bank account numbers are inserted into an AVL tree. The AVL tree automatically maintains balance using rotations during insertion. The inorder traversal of the tree generates a sorted sequence of account numbers. This sorted sequence is then used to construct a balanced BST by recursively selecting the middle element as the root.

Finally, the heights of the rebuilt balanced BST and the AVL tree are calculated and compared. This comparison helps demonstrate how different tree construction techniques affect tree height and the efficiency of searching operations.

The project illustrates important data structure concepts such as tree traversal, recursion, AVL rotations, balanced tree construction, and time complexity. It provides a practical example of how tree-based indexing can be used to organize bank account records and support efficient searching.

### Objectives

- To store bank account numbers using tree data structures.
- To construct an AVL tree through insertion.
- To obtain a sorted sequence using inorder traversal.
- To rebuild a balanced BST from the inorder sequence.
- To calculate and compare the heights of both trees.
- To understand the efficiency of balanced trees in searching and indexing.

### Technologies Used

- Programming Language: C++
- Data Structures: Binary Search Tree (BST), AVL Tree
- Concepts: Recursion, inorder traversal, tree rotations, and height calculation

### Conclusion

This project demonstrates how balanced tree structures can improve the organization and retrieval of bank account records. By comparing a rebuilt balanced BST with an AVL tree, it helps us understand tree balancing techniques and their impact on search efficiency.
